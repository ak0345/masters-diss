# notebooks/

Exploratory only. Nothing in the dissertation depends on these, and nothing in the pipeline
calls them.

- `play.ipynb` — scratch work: loading a checkpoint, sampling a few molecules, eyeballing
  rewards and coordinates.
- `colab.ipynb` — a Colab-shaped setup cell for running the same thing on a hosted GPU.

Every number and figure in the manuscript comes from `scripts/`, `ablations/`, `figures/` or
`results/`. If a notebook and a pipeline script disagree, the pipeline script is correct.
